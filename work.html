Zerova / Zystra VPN

StackFlutter · Dart · Kotlin · WireGuard
PlatformsAndroid (Google Play)
TypeVPN client · rebrand lifecycle
RoleMobile engineering · publishing

A cross-platform VPN client built on a WireGuard core, with native tunnel management, multi-region server selection, and a complete privacy and rebrand lifecycle — designed, built, signed and shipped to Google Play.

The problem

The client needed a real VPN — not a wrapper around a third-party SDK, but a proper tunnel with native service integration, reliable connection state and store-compliant privacy handling. It also had to survive a full rebrand from Zerova to Zystra without breaking existing installs.

What we built

  • Native Android tunnel via VpnService with the WireGuard core, Flutter UI as a thin state reflector.
  • Full connection lifecycle — connect, disconnect, reconnect-on-network-change and a foreground notification.
  • Multi-region server selection with latency-aware defaults.
  • VPN service declaration, data-safety form and privacy policy written to match real behaviour.
  • Signing-key continuity preserved through the rebrand so Play treated the new identity as an update.

Outcome

A production VPN client delivered through the full store lifecycle, including VPN declaration, data-safety compliance and a rebrand handled without losing update continuity.

Automation · Finance

AI Trading Bot

StackPython · MQL5 · Pine Script · CDP
PlatformsMetaTrader · Web dashboards
TypeAutonomous research system
RoleSystems & ML engineering

A self-improving trading research system that records market data, learns a direction model, validates it honestly, and only trades horizons that pass a statistical edge test — with a live console read-out and layered risk controls.

The problem

Manual trading is inconsistent and emotional. The goal was a system that executes a defined strategy identically every time, tracks performance in real time, and limits downside automatically.

What we built

  • Separated strategy (Python models) from execution (MQL5) so signal logic could evolve independently.
  • A purged walk-forward validation gate that decides which horizons are tradeable.
  • Risk controls: position sizing, maximum drawdown, daily loss caps and hard stop-losses.
  • A live dashboard for PnL, open positions and strategy health, plus Pine Script indicators for chart validation.
  • Full decision logging so strategy changes can be evaluated against real outcomes.

Outcome

A disciplined execution engine that runs the strategy consistently, with the risk layer enforcing limits no matter what the market does. Built and validated on a demo account.

Utility · Open Source

NetCarve — Subnet & CIDR Calculator

StackKotlin · Android
PlatformsAndroid
TypeOffline networking utility
RoleDesign · engineering · release

A free, ad-free, fully offline networking utility for network engineers, cloud architects and DevOps teams. NetCarve performs precise IPv4/IPv6 subnet math and VLSM planning entirely on-device using integer binary arithmetic.

The problem

Network engineers often work in air-gapped or restricted data centres where network access is unavailable — and most subnet calculators phone home, carry ads or track users.

What we built

  • Exact subnet math derived from integer bit operations — correct for every prefix length.
  • Requests no internet permission, contains no ads and no trackers.
  • VLSM planning and a binary bit view with copy-to-clipboard on every value.
  • Engineer-first UI with instant results, shipping under the MIT license as an open-source showcase.

Outcome

A genuinely private, offline-by-design tool trusted by engineers — and a public showcase of production-grade native software.

Reference · Mobile

AniEye — Offline Watch-Order Guide

StackKotlin · Android
PlatformsAndroid (min SDK 24)
TypeSingle-purpose reference app
RoleProduct · engineering · release

A fully offline anime watch-order guide: pick a series and see its recommended viewing order — seasons, arcs, films and optional entries, numbered step by step.

The problem

Fans constantly ask "which order should I watch this in?" but existing answers are buried in forums and wiki pages that require connectivity and are cluttered with ads.

What we built

  • 14 popular series with step-by-step watch orders and 89 numbered steps.
  • Optional steps (films/OVAs/spinoffs) clearly flagged, plus instant search by name.
  • Zero permissions, no internet permission, no ads, no analytics, no stored data.

Outcome

A fast, private, ad-free reference app that works entirely offline — a clean example of shipping a focused product well.

AI · Mobile

AI-Powered Mobile Apps

StackOpenAI · Gemini · Flutter · Kotlin
PlatformsAndroid & iOS
TypeAI product development
RoleAI + mobile engineering

Android and cross-platform apps with integrated LLM features — conversational chatbots, image understanding, voice interaction and smart recommendations — built for real users rather than demos.

The problem

Clients wanted genuine AI capabilities without the fragility that comes from calling a model directly from UI code. AI calls fail, latency varies, and costs need watching.

What we built

  • All model access wrapped behind a single AI service seam that owns prompts, retries, caching and fallbacks.
  • Streaming responses so users see progress immediately.
  • Graceful non-AI fallbacks so apps stay usable when the model is unavailable.
  • On-device classification for cheap tasks, cloud models only where needed — cutting cost and latency.
  • Instrumentation of the AI path: success rate, latency and fallback frequency.

Outcome

AI features that behave predictably in production — responsive under load, resilient to outages and cost-controlled through hybrid routing.
